## three sentences

1. The blackboard paradigm (Hearsay-II 1971–76, Nii's 1986 canon, BB1 1985,
   GBB commercialization to ~1998) was **never falsified**: it died a
   compound death — flagship loss on *cost at equal accuracy* to a compiled
   monolith (Harpy, DARPA SUR 1976: "2 to 20 times slower"), substrate loss
   of its hand-coded knowledge sources to learned statistical models
   (HMM sweep, mid-1980s), then absorption-by-reframing into multi-agent
   systems (Carver 1997: textbooks just stopped mentioning it; Corkill 2003:
   MAS as "revisiting the collaborating-software paradigm from an
   agent-centric orientation") — and nobody inside the field ever wrote an
   obituary (a certified null: it has a missing-persons report, not a death
   certificate, until this dig wrote one).
2. The death certificate is **PARTIALLY VOIDED** by LLMs — all three arms
   reached this independently: the knowledge-source clause is cured (the
   thing that killed the KS layer is now the KS; authoring a KS is writing a
   brief), but the per-deliberation-step cost clause is *strengthened*
   (every opportunistic scheduling decision is now metered inference) and
   the control clause is capability-independent (smarter KSs generate more
   plausible competing hypotheses — worse for herding, not better); the
   deepest surviving clause is **Harpy-redux**: modular cooperation loses to
   integrated capability whenever one system can swallow the task, and the
   2026 Harpy is a single strong long-context model.
3. The 2026 wave is split into a **blackboard-aware lineage** (arXiv
   2510.01285 — which reports 13–57% relative improvement over master-slave
   frameworks, abstract-level, with NO cost-matched single-agent control in
   the abstract; 2507.01701; 2510.14312 Terrarium; ARIADNE; PatchBoard) and
   a **stigmergy-only lineage** (SwarmWorld 2608.26081, whose search-visible
   framing credits Grassé's termites and never the blackboard — citation
   absence still unverified first-hand after seven diggers, the
   load-bearing hearsay of this lead), and NEITHER lineage shows any
   engagement with the *lessons* literature: zero evidence anywhere of a
   2025–26 paper citing Hayes-Roth 1985 (control), Carver & Lesser 1994
   (control evolution), Corkill 1991 (why it never attained its potential),
   or Hayes-Roth & Lesser 1977 (focus of attention). The architecture is
   cited; the fifteen-year bill for running it is not.

## Q1 · death certificate (adjudicated)

ranking disagreement (A1: "ugly" primary; ant-a: timing/efficiency primary)

**cause of death = (1) 1976 flagship cost-loss, (2) mid-80s KS-substrate
loss to learned models, (3) 1990s framing/succession — with (1) written as
"ugly-shaped timing": the wound was cost, the humiliation was losing to
brute force at its own birth event.**

## Q2 · the six walls (compressed transfer table)

1. **Control** — "features responsible for flexibility make effective
   control difficult" (Carver & Lesser 1994). Fifteen years of head-creep:
   Hearsay-II scheduler → HASP → CRYSALIS → DVMT → BB1 (control recursed
   onto its own blackboard) → RESUN. 2026 re-hit: orchestration policy;
   LbMAS already rebuilt "decider, planner, critic, conflict-resolver" in
   prompts.
2. **Deliberation cost** — 2–20x vs Harpy; Corkill's own exit ramp
   (prototype on the blackboard, then "reimplemented without the blackboard
   structure", 1991, extract). 2026 re-hit: token-priced deliberation;
   "every successful swarm run is training data for its own compiled
   replacement" (ant-b).
3. **Focus/herding** — dedicated attentional theory needed by 1977
   (Hayes-Roth & Lesser). 2026 re-hit: worse — LLM agents also *imitate*
   each other's text; traces lack the credibility ratings Hearsay-II
   hypotheses carried.
4. **Shared-state scaling** — the board becomes the serialization point
   (Decker et al. 1991; Cage/Poligon built for exactly this, speedup
   numbers NOT recovered — null). 2026 re-hit: read-whole-board-per-wake =
   the same bottleneck denominated in tokens.
5. **Engineering cost** — "design choices in a void," no decomposition
   theory (Corkill 1991; Nii Part II). **The one wall LLMs partially
   dissolve** (KS = system prompt) — but the decomposition half stands:
   role-prompt folklore replaced KS folklore.
6. **Evaluation** — near-null, and the absence IS the finding (ant-b): one
   bake-off ever (1976), lost on a metric it hadn't optimized, no
   evaluation culture built; nothing falsifiable defended the paradigm when
   funding moved. Walls trade off: dropping the scheduler buys scaling by
   paying herding; no design in the record dodged both.

## Q3 · revival verdict

**Revival candidate — partial.** Voided: KS cost/capability clause (and
wall 5's authoring half). Standing: per-step cost (strengthened by token
pricing), control (capability-independent), Harpy-redux (strengthened —
long-context absorption). Practical clause, all arms concurring: revive the
*medium and integration* ideas; do NOT revive opportunistic per-event LLM
control without a cheap procedural condition layer; and never spend a swarm
on a task without an argument that it exceeds single-model absorption.
Truth axis: pass. Value axis: pass (live 2026 substrate question). Freedom:
candidate only, unreviewed.

## Q4 · proposed changes to gold-digger (operator decides at gate)

Convergent across arms that could not see each other — the crossing is the
evidence: the head-arm digger argued for the board, the swarm's last ant
argued for the head, the single session argued for both and against itself.

1. **Routing rule replaces architecture identity** (ant-d R1 + Corkill exit
   ramp as revolving door): novel lead-type → swarm (structure discovery);
   recurring lead-type → compiled head+brief pipeline distilled from a
   prior swarm run's board; small task → single session. The board of a
   good swarm run IS the brief-writer's raw material.
2. **Harpy-redux gate check** (ant-c hook, ant-d R2, C independently): no
   multi-agent spend without one line at approval stating why the lead
   exceeds single-session absorption. The honest A/B baseline is C — this
   run built one only because the swarm demanded it.
3. **Shared per-lead board as default for multi-digger leads** (A3 prop 2 —
   from the HEAD arm): `LEAD-ID.board.md`, appended with attribution;
   isolation demoted to a declared experimental mode for controlled
   comparisons. C's knife kept attached: don't let evaluation hygiene
   become the production pattern — that's running the isolated-search
   baseline SwarmWorld beat.
4. **Keep the head dumb and procedural; keep both human gates** (A3 props
   1, 6; ant-d R3): the head has full observability while diggers are
   homogeneous, so 2510.01285's anti-head argument does not yet apply — its
   own stated scope condition is the controller "lacking full
   observability." Switch trigger, concrete: first real digger
   heterogeneity (tool permissions, caches, mixed models). The operator +
   taste file IS the control blackboard; automating it = re-running 1985
   with worse unit economics.
5. **Standing bake-off with declared metric** (ant-d R4): every
   architecture change rides with a same-lead A/B (and a C arm), metric
   declared before running — because wall 6 is the one that kills quietly,
   and 1976 says whoever defines the metric decides which architecture
   survives.
6. **Control-machinery cap** (ant-d R5): track pure-coordination-entries /
   total per swarm run (this run: 25%). Sustained growth = BB1 alarm; the
   fix is compile (rule 1), not govern harder.
7. **Cheap steals**: BB1's auditability — head writes dispatch reasoning
   onto the record so gates can audit *why* a dig was commissioned (C);
   Linda-style content-addressable tripwires on death files — match by
   content, not neighborhood, procedural grep, no model call (A3 prop 3).
8. **Per-lead step/token budget in the runbook** (A3 prop 5): both eras
   testify shared-medium systems die of per-step cost; generalize the
   existing verification-dig cap.

## declared metaphors / smuggling
